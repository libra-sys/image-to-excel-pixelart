图片转Excel像素画工具使用说明

一、功能介绍
本工具可以将任意图片转换为Excel格式的像素画，每个像素对应Excel中的一个单元格，通过设置单元格颜色来还原图片效果。

二、安装步骤
1. 确保您的计算机已安装Python 3.6或以上版本
2. 打开命令提示符（CMD）或PowerShell
3. 运行以下命令安装必要的库：
   pip install pillow openpyxl

三、使用方法
1. 将您要转换的图片和本脚本放在同一目录下（或记住图片的完整路径）
2. 打开命令提示符（CMD）或PowerShell
3. 切换到脚本所在目录（例如：cd e:\excel）
4. 运行脚本：
   python image_to_excel_pixelart.py
5. 按照提示输入相关信息：
   - 图片路径：输入您要转换的图片的完整路径（如：test.jpg 或 D:\images\photo.png）
   - 输出Excel路径：输入生成的Excel文件保存路径（默认：output.xlsx）
   - 像素大小：输入每个像素的大小（默认：20，值越大像素块越大）
   - 最大尺寸：输入图片的最大边长（默认：100，防止图片过大导致Excel性能问题）

四、参数说明
- 图片路径：必填，支持常见图片格式（JPG、PNG、BMP等）
- 输出Excel路径：可选，默认生成output.xlsx文件
- 像素大小：可选，推荐值10-50，值越大生成的Excel文件越大
- 最大尺寸：可选，推荐值50-200，防止生成的Excel文件过大影响性能

六、注意事项
1. 图片分辨率过高时，建议适当减小最大尺寸，否则生成的Excel文件可能会很大
2. 像素大小建议设置在10-50之间，过小会导致像素不清晰，过大则文件体积过大
3. 转换过程中请耐心等待，大图片可能需要较长时间
4. 生成的Excel文件在打开时可能需要启用编辑功能
5. 某些图片格式可能不被支持，请先转换为JPG或PNG格式

七、常见问题
Q：为什么转换后的图片颜色与原图有差异？
A：Excel支持的颜色范围与图片格式有所不同，可能会有轻微的颜色偏差。

Q：为什么转换后的Excel文件打开很慢？
A：可能是因为图片尺寸过大或像素大小设置过高，建议减小最大尺寸或像素大小。

Q：运行脚本时提示"No module named 'PIL'"怎么办？
A：请确保已正确安装Pillow库，运行命令：pip install pillow
